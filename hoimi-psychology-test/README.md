# 🧪 ホイミー心理テスト

ドラゴンクエストシリーズの人気キャラクター「ホイミー」をモチーフにした心理テストアプリです。

あなたの癒やし系タイプを診断して、自分に合ったホイミーのタイプを見つけましょう！

![](https://img.shields.io/badge/React-18-61DAFB?style=flat-square&logo=react)
![](https://img.shields.io/badge/Vite-5-646CFF?style=flat-square&logo=vite)

## ✨ 特徴

- **8つの質問**で簡単診断
- **4つの診断タイプ**
  - 聖なるホイミー ✨
  - アクティブホイミー ⚡
  - フレンドリーホイミー 🌟
  - ピースフルホイミー 🌙
- **美しいUI**とスムーズなアニメーション
- **レスポンシブデザイン**（PC・タブレット・スマホ対応）
- **結果シェア機能**（クリップボードにコピー）
- **何度でも診断可能**

## 🎮 診断タイプ

### ✨ 聖なるホイミー
思いやりと優しさに満ちたタイプ。周りの人の痛みに敏感で、いつも誰かのために力を使うことができます。

### ⚡ アクティブホイミー
元気いっぱいのタイプ。前向きなエネルギーで周りを明るくし、困難も笑顔で乗り越えていきます。

### 🌟 フレンドリーホイミー
人との繋がりを大切にするタイプ。チームワークを重視し、みんなと一緒に成長していくことが得意です。

### 🌙 ピースフルホイミー
穏やかで落ち着いたタイプ。静かな存在感が周りの人に安心感を与えます。

## 🚀 セットアップ

### 前提条件
- Node.js 16以上
- npm または yarn

### インストール

```bash
cd hoimi-psychology-test
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5174` にアクセスします。

### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist` フォルダに出力されます。

## 🎯 使い方

1. **スタート画面**
   - 「診断をはじめる」ボタンをクリック

2. **質問回答**
   - 8つの質問に順番に答えていく
   - 各質問に4つの選択肢
   - プログレスバーで進捗確認

3. **結果表示**
   - あなたのホイミータイプが表示される
   - 癒やし力をパーセンテージで表示
   - 特徴とアドバイスを確認
   - 「結果をシェア」でクリップボードにコピー
   - 「もう一度診断する」で再診断

## 🎪 機能詳細

### 質問システム
- 8つの質問で構成
- 各回答に type（A-D）と points（1-3）を設定
- 合計ポイントで診断タイプを決定

### 診断アルゴリズム
各回答のポイントを type ごとに集計し、最も高いポイントのタイプを結果として表示します。

### シェア機能
- Web Share API対応（モバイル）
- Clipboard API対応（PC）
- シェアテキストに診断結果を含む
